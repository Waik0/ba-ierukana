# ブルアカ生徒いえるかな？

ブルーアーカイブの生徒を何人言えるかチャレンジするブラウザゲーム（非公式ファンメイド）。

## 遊び方

`index.html` をブラウザで開く（ビルド不要・サーバー不要）。

- 出題範囲（全員 / 学校別）を選んで「開始」
- 名前を入力すると、正解した瞬間に自動で埋まる
  - ひらがな・カタカナ・半角カナ・フルネーム（漢字 / よみ）に対応
  - Enter で確定して不正解なら「いない / もう言った / 別の学校の生徒」を表示
- 全員言えたらクリアタイムを表示（学校ごとに自己ベストを保存）
- 「降参」で言えなかった生徒を赤で表示
- オプション: 効果音 / 自動スクロール / 部活ヒント（空欄に部活名を表示）

## 生徒データの更新

新しい生徒が実装されたら、以下で `data/students.js` を再生成する。

```
py tools/build_students.py
```

データは [SchaleDB](https://schaledb.com/) から取得し、衣装違い（「アル（正月）」など）は同一人物としてまとめている。
